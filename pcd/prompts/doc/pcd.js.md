# 更新：pcd.js（构造器加第三参 prompts，fill 算索引偏移）

变化集中在两处：

- **构造器**：`constructor(data, ids, prompts = [])`，默认空数组——不传时行为与上一版完全一致（默认参数保旧兼容）
- **fill**：开头一行 `const offset = this.prompts.length > 0 ? 1 : 0`；拼键处 `selectedIndex - offset`；填列表前若该级有提示文字，先插一个 `new Option(提示, '')`（值为空串，表单校验可据此识别「未选」）

为什么必须减 1：提示项占据了选项 0 的位置，此后所有真实数据的序号整体后移一格—— selectedIndex 读到的是「含提示项的位置」，而键路径需要的是「数据里的位置」。**头插一行 UI，索引全体偏移**，这是所有「列表头插提示」类控件共同要交的税，漏掉就是经典的错位 bug。

至此控件在真实项目里可直接搬走：数据、id、提示三参定形。
