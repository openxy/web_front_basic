# 索引路径数据

## 这个项目是什么

「省市区三级联动」是多版本演进的教学项目：选省出市、选市出县的三个下拉框。原课程是一个一次写成的插件（pcd.js 的 `PCD` 构造函数），本线把它按功能与技术拆开，一版一个概念地演进：先认识数据，再联动两级，再级联三级，再封装成控件，最后加提示项。数据文件 `pcd-data.js`（全国真实数据）原样入册，所有版本共用同一份，从头到尾不变。

## 本版本引入的概念

**索引路径编码**：省→市→县是一棵树，但数据不是嵌套对象，而是一张扁平的键值表——键是索引路径：

- `"0"`：省级名称列表（31 项）
- `"0_2"`：第 3 个省（河北省）的城市列表
- `"0_2_1"`：其中第 2 个市的区县列表

层级关系藏在下划线分隔的序号里。孩子挂在父级的「第几个孩子」上，不用 id、不用嵌套，查表即得——代价是中间删一个省，整棵子树的键全要重排（教学语料静态不变，正好躲开）。

**Option 构造器**：`new Option(文字, 值)` 生成一个选项，`select.add()` 入列——填充下拉框的标准姿势。

## 本版本的改动

- `pcd-data.js`：原课程数据原样入册（`var pcdData = {...}`，传统全局 script 引入，浏览器里人人可读）
- `index.html`：读 `pcdData['0']`，for-of 逐项 `add(new Option(name, name))`

## 关键代码走读

- 打开控制台敲 `pcdData['0_2']`、`pcdData['0_2_1']`：亲手摸一遍键的规律，比读十行文档管用
- `new Option(name, name)`：文字与值同串——本线的键是序号不是名字，选项值用不上，先占着位
