# 新增：pcd-data.js（全国省市区数据，一棵树编码成一张扁平表）

文件 4000 行，但结构只有一句话：一个 `var pcdData = {...}` 大对象，**键是索引路径，值是名称数组**：

- `"0"`：省级名称列表（北京市、天津市、河北省……）
- `"0_2"`：第 3 个省（河北省）的城市列表
- `"0_2_1"`：其中第 2 个市的区县列表

层级关系不靠嵌套表达，藏在键的下划线里：每往下一层，键就多拼一段「当前级的选中序号」。数据是原课程数据文件原样入册（`var` 全局声明，脚本标签加载即得全局变量 `pcdData`）。

页面脚本（index.html 里）只做一件事：读 `pcdData['0']`，`new Option(name, name)` 逐个塞进省级 select。在控制台敲 `pcdData["0_2"]` 可以亲手验证键的拼法。

树为什么要压扁成键值表？——取「某省某市某区」时，按选中序号拼键一步查到，不用沿树逐层下钻。这是用空间换查找简单性的经典编码。
