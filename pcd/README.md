# 省市区三级联动（pcd 案例）

## 本案例教什么

用一个经典控件（省市区三级联动下拉）串起 DOM 操作与事件的核心功：先定数据组织（树编码成扁平键的索引路径），再事件联动（change），再递推填充（级联），然后封装（class 控件），最后细节修正（提示项与索引偏移）。

数据文件（省市区数据）原样入册不改，逻辑由原课程实现现代重写。

## 版本导览

| # | 版本 | 概念要点 |
| --- | --- | --- |
| 01 | [索引路径数据](#v=pcd/data) | 树编码成扁平键："0" 省列表、"0_2" 其第 3 省的城市、"0_2_1" 再下一级 |
| 02 | [onchange 联动](#v=pcd/onchange) | change 事件 + selectedIndex 拼键，两级下拉第一次联动 |
| 03 | [三级级联](#v=pcd/cascade) | 任一级变化，从该级到末级全部重刷 |
| 04 | [封装成控件](#v=pcd/widget) | 过程代码收进 class PCD，页面一行调用 |
| 05 | [提示项与索引偏移](#v=pcd/prompts) | 「请选择」占位项与索引减 1 修正 |

## 重点与边界

- 重点：数据结构先行——树变成扁平键之后，联动就只剩「拼键取数」
- 边界：异步加载数据、组件框架做法不在本案例
