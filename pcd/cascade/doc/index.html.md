# 更新：index.html（fillProvince/fillCity 合并成一个 fill(from)）

上一版两个填充函数的差别只有「键拼几段、填哪个框」。本版把它统一成循环递推：

- **外层** `for (let v = from; ...)`：从第 from 级填到末级
- **内层**：第 v 级的键 = `'0'` 加前 v 级各自的 `selectedIndex`，用 `_` 连起来
- 填之前 `innerHTML = ''`，逻辑与上一版相同

事件绑定只剩两条：省变 → `fill(1)`（市、区县全重刷），市变 → `fill(2)`（只重刷区县）。**从变化的那一级刷到末级**——下级依赖上级，上级一变下级全部作废，这个「重刷范围」正是级联控件的语义本体。

上级没选时键查不到（`pcdData[sid]` 为 undefined），`?? []` 按空列表处理，下拉呈现为空而非报错。

三个填充循环收成一个循环之后，下一步是把整段过程收成一个类——见 `widget` 版。
