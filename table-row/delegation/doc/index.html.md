# 更新：index.html（新增 tbody 监听器，删掉逐行绑定的可能）

在上一版两个绑定之外，新增了本版的核心——tbody 上的一个监听器，接住**所有行**的点击：

- `event.target` 是实际被点的元素（可能是 `a`，也可能是它里面的文本节点）
- `closest('.remove')` 从被点元素沿祖先链向上找，命中才说明点的是删除链接；没命中直接 `return`，别的点击一概不管
- `link.closest('tr')` 再向上一次找到所属行，`remove()` 删掉整行——不需要知道它是第几行

这就是事件委托的三要素：监听器只挂一个（tbody）、靠冒泡接住后代的事件、用 `closest` 反查事件来源。新增的行是将来才插入的，但点击照样冒泡到 tbody，所以**天然被覆盖**——这是逐行绑定做不到的。
