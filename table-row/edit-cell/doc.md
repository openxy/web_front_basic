# 点击编辑

## 本版本引入的概念

**原地替换**：`replaceWith` 把一个元素从 DOM 里换下来，换上一个新元素——位置不变，身份变了。`ChangeCell` 把 td 换成 input，表格里从此有了「变身」。

**替换即失忆**：监听器长在元素身上，元素离场，监听器随之作废；新造的元素一律是白纸。旧 td 的 onclick 随它一起退场——本版无碍（td 的使命已尽），但它是下一版的题眼。

## 本版本的改动

- 生成行的三个数据单元格接上 `onclick='ChangeCell(this);'`（操作列不加——删除链接不是编辑对象）
- 新增 `ChangeCell(o)`：把被点的 td 替换成 `<input type='text' class='current'>`，然后 `$("input.current").focus()` 聚焦

## 关键代码走读

- 生成的 input 此刻**没有任何事件**：没有 onblur、没有 onkeydown——它出现了，但还交不了差。提交是下一版的概念
- `$("input.current").focus()`：按类名找到 input 并聚焦。不聚焦的话用户得先点一下输入框才能打字，编辑体验就断了
- input 的 value 是空的：原格子的文字没有拷进来，编辑即重写（原课程如此，见思考题）

## 对照要点

- 与上一版比：字符串里三个 td 各加一个属性，外加一个新函数
- 至此页面有三种行内 onclick：增加（页面链接）、删除（生成链接）、编辑（生成单元格）——同一机制的三个用场
