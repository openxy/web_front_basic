# 删除一行

## 本版本引入的概念

**this 实参**：行内 onclick 里写 `RemoveRow(this)`，`this` 就是正在被点的那个元素。元素把自己交给函数——不需要编号，不需要查找。

**jQuery 链式上溯**：`$(o).parent().parent()` 从链接出发走两级：`a` → `td` → `tr`，链尾 `.remove()` 把行删掉。jQuery 的链式调用一步一对象：每个方法返回新的 jQuery 对象，可以一直点下去。

## 本版本的改动

- 生成行的字符串里，删除链接接上行为：`onclick='RemoveRow(this);'`
- 新增 `RemoveRow(o)`：三行代码——上溯两级、删行

## 对照要点

- 与上一版比：生成的 HTML 字符串多了一个属性，摆设链接变成真删除
- 删除不问「我是第几行」，从元素自身出发向上找到所属行——位置会变，归属不会
- 依赖写死编号的写法（如 `del(1)`）在删除中间行后会错位删错行；`this` + 上溯天然没有这个问题

## 思考题

- 若删除链接里再嵌一层 `<span>`（`<a><span>删</span></a>`），`parent().parent()` 删掉的还是整行吗？
- jQuery 有个更稳的上溯办法 `closest('tr')`——它与逐级 `parent()` 的差别是什么？嵌套多深都不怕的是哪个？
