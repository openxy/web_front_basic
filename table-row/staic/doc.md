
## 这个项目是什么

「名单管理」是一个多版本演进的教学项目：从一张写死的表格出发，一步步给「删除」按钮接上真实行为，借此对比各种事件绑定方式的差别。

规则很简单：每个版本只引入一个概念，代码始终是一个可以直接双击打开的 `index.html`。

## 本版本的页面

纯 HTML + CSS，没有一行 JS：

- 一张三行表格：姓名、邮箱、操作三列，数据全部写死在 HTML 里
- 操作列每行一个「删除」按钮，目前只是普通按钮
- 样式只有基础版式：表格边框、表头底色、按钮手势

## 对照要点

- 记住这个起点：结构、数据、按钮全在 HTML 里，页面完全静态
- 点一点「删除」——没有任何反应。按钮天生不带行为，行为要等 JS 来接

## 思考题

- 不写一行 JS 的前提下，「删除」按钮有可能真的删掉一行吗？为什么？
