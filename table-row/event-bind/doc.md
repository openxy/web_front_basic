# 事件绑定

## 这个项目是什么

「表格行操作」是一个多版本演进的教学项目：原始课程是一个 jQuery 页面（增行、删行、点击编辑单元格），本线把它改写为现代原生 JavaScript，拆成一版一个概念的演进链，相邻版本的 diff 都能一句话说清。

规则很简单：每版只引入一个事件/DOM 概念，代码始终是一个单独的 `index.html`——零依赖，双击就能打开。

## 本版本引入的概念

**事件绑定**：`addEventListener(事件名, 回调)` 把监听器挂在元素身上，事件发生时回调被调用。原课程把 `onclick` 写在 HTML 属性里（行内绑定）；现代写法结构与行为分离——HTML 只管结构，行为全部收进脚本。

**事件对象**：回调的第一个参数 `event` 是浏览器递来的事件对象，携带事件的全部信息。本版只用了一招：`event.preventDefault()` 拦下 `a href="#"` 跳锚点的默认行为。

## 本版本的改动

- 页尾 `<script>`：常量钩子（`add` 链接）+ 一个监听器 + 一个函数
- `addRow()`：模板字符串（反引号）拼一行 HTML，`insertAdjacentHTML('beforeend', ...)` 塞进 tbody 末尾

## 关键代码走读

- `const`：现代 JS 的常量声明，钩子元素取名后全页复用
- 模板字符串里的换行与缩进会原样进入 HTML，浏览器不在乎，可读性归人
- 生成的行里「删除」链接还什么都没接——下一版的概念

## 对照要点

- 与原课程比：`onclick="AddRow();"` 属性消失，绑定进了脚本——打开页面看不到行为，行为集中在代码里
- `insertAdjacentHTML` 对应 jQuery 的 `append(字符串)`：零依赖达成同样的效果

## 思考题

- 把 `event.preventDefault()` 删掉再点链接：地址栏多了个 #，页面还有什么变化？（长页面会跳回顶部——默认行为没拦住）
- 本线的页面双击 file:// 直接能开；spa 线的 es-modules 版为什么不行？（提示：import map 与模块加载的 CORS 限制）
