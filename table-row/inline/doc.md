
# 行内 onclick

## 本版本引入的概念

**行内事件绑定**：`onclick` 写在 HTML 属性里，值是一段 JS 调用。浏览器解析到这个属性，监听器就挂好了——不需要任何 JS 代码去「找元素」。

参数也一起写在 HTML 里：`onclick="del(0)"` 的 `0` 是字面量，每行各自带自己的编号。

## 对照要点

- 三行的删除按钮分别是 `del(0)` / `del(1)` / `del(2)`：行为跟着 HTML 走
- 删除一行试试，正常。但**删除中间一行后**再点下一行的删除——仔细看删掉的是谁（伏笔，第三版揭晓）

## 思考题

- `del(i)` 收到的编号，写死的时点与页面当前状态一致吗？删掉一行之后还一致吗？
