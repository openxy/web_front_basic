
## 本版本引入的概念

**行内事件绑定**：`onclick` 写在 HTML 属性里，值是一段 JS 调用。浏览器解析到这个属性，监听器就挂好了——不需要任何 JS 代码去「找元素」。

参数也一起写在 HTML 里：`onclick="del(0)"` 的 `0` 是字面量，每行各自带自己的编号。

## 本版本的改动

在上一版静态表格的基础上：

- 三行的删除按钮分别写上 `onclick="del(0)"` / `del(1)` / `del(2)`：行为跟着 HTML 走
- 表格加了 `id="list"`，页面末尾多出一个 `<p id="tip">`，都是留给 JS 的钩子
- 底部新增 `<script>`：`del(i)` 按编号找到对应行删掉，并在 `#tip` 里报告删了第几行
