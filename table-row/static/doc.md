## 这个项目是什么

「表格行操作」是一个多版本演进的教学项目：原始课程是一个 jQuery 页面（增行、删行、点击编辑单元格），本线把它拆成一版一个特性的演进链，相邻版本的 diff 都能一句话说清。

规则很简单：每版只引入一个概念，代码始终是一个单独的 `index.html`。

## 本版本的页面

纯 HTML + CSS，没有一行 JS：

- 一张四列表格：栏目一、栏目二、栏目三、操作，tbody 是空的
- 表格上方一个红字提示区 `.info`（空着，留给校验消息）
- 表格下方「增加一行」链接，点了只会跳一下锚点（`href="#"`）

## 对照要点

- 记住这个起点：结构、链接全在 HTML 里，页面完全静态
- 点一点「增加一行」——地址栏多个 #，别的什么都没发生。行为要等 JS 来接
- head 里连脚本都没有：jQuery 要到下一版才入场
