# index.html（列表页——「每个页面一个文件」的静态网站）

本版目录里 11 个 HTML 互相链接成站：`index.html` 列表、`show-1.html` 详情、`new.html` 新建、`edit-*.html` / `delete-*.html` 各三份（每篇帖子一套）。

列表页就是一张写死的 HTML 表格：每行的标题链到 `show-1.html`，「改」「删」链到对应页面。数据、结构、导航三位一体固化在标记里——**第 4 篇帖子 = 复制一份 show-1.html 改文字**，新增、编辑、删除全部等于「改 HTML 文件」。

比上一版（文件系统）进的地方：能经浏览器看、有排版、能互相链接。没解决的地方照样明显：内容与页面一一对应，改一个标题要动 N 个文件。让「页面」与「内容」分开——下一版引入模板。
