
# 前端路由与单页应用（SPA）

## 本版本引入的概念

**前端路由**（`lib/simple_hash_router.js`）：监听地址栏 `#` 后面的部分，按规则表把 `/posts/1001` 这样的模式分发到对应函数。本版路由表只有两条：`/`（列表）与 `/posts/:id`（详情）。

**单页应用（SPA）**：从本版起整个应用只有一个 HTML，页面切换只是 `#main` 内容替换，浏览器不整页刷新。

数据仍是 `app.js` 里写死的数组；详情页就是在控制器里就地 `find` 一下。

## 操作

- 列表点标题进详情：注意地址栏 hash 变了、页面没有整页刷新；点「首页」回列表
- 点「新增 / 改 / 删」：地址栏变了，页面显示 404——路由表里还没有这些规则

## 局限

- 列表页上的「新增/编辑/删除」链接是死的：本版是只读应用
- 数据查找直接写在控制器里
