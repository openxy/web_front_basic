# 动态渲染

## 本版本引入的概念

**数据驱动渲染**：页面内容不写在 HTML 里，而是一个数据数组在脚本里，渲染函数把数据拼成 HTML 塞进容器。元素不是文档里写死的，是脚本运行时诞生的——「动态元素」说的就是它们。

**直接绑定**：渲染完立刻 `querySelectorAll` 逐个挂监听。此刻元素已经存在，绑定有效——初始的八张图都能点，点一下加高亮描边。

## 本版本的改动

- 起步版：数据数组 + SVG 渐变当图 + `render()` 整片渲染 + `bindPicks()` 逐个绑定

## 关键代码走读

- `photos.map(...).join('')`：数据到 HTML 的最短路径——一个数组进、一段字符串出，`innerHTML` 一次性放进容器
- `photoUrl()`：渐变色转 data URI，案例零外部请求、离线可跑；真实项目里这里就是图片地址
- `bindPicks()` 在 `render()` 末尾调用：绑定必须在元素存在之后——先渲染、后绑定，顺序不能反
