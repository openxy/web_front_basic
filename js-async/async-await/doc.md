# async/await

## 本版本引入的概念

**async/await**：给 Promise 换一层同步的写法。`async` 函数里，`await compute()` 的意思是「等这个 Promise 完成，再往下走」——读起来跟第一版的同步代码一个形状，但主线程照常喘气（时钟在走就是证明）。

上一版思考题里「忘了 return 链就断」的暗坑在这里消失了：await 写在哪儿就等在哪儿，看得见。错误处理也回归大家最熟的形状——一个 try/catch 包住整段，任何一步抛异常都落进 catch。

## 两套写法，一个机制

await 不是新机制，是 then 链的语法糖：`await compute()` 大致等于「compute() 完成后再做接下来的事」。链条在底下照旧运转，所以 then 与 await 可以混用。选哪个是可读性题：先后顺序强烈的流程（先 A 再 B 再 C）用 await 顺眼；组合、并行这类链式工具擅长的事（下一版）then 家族更直接。

## 本版本的改动

只有点击处理变：五节 then 链改为 async 函数里三段 `await compute()` 加日志，try/catch 收口。compute 与 index.html 一字未动——同一机制的另一种写法。
