# 循环陷阱

## 本版本引入的概念

**var 循环 + 闭包 = 经典事故**。页面新添三个编号按钮，脚本想给每个按钮挂「点我显示我的编号」的监听。写法看起来天经地义：循环三次，每次给 `btns[i]` 挂一个箭头函数，函数体里用 i。可点任何一个按钮，显示的都是 3。

原因接上一版：「函数捕获的是环境，不是快照」。var 的 i 在整个循环只有**一个绑定**：三个箭头函数捕获的都是它；循环结束时它的值走到 3；而点击发生在循环之后——无论点谁，读到的都是终值 3。

对照上一版的工厂：`createCounter()` 每调一次造一个新环境，所以两个计数器互不相认；这里三个箭头函数共享同一个环境，所以读出同一个 i。闭包没有坏，是 var 的绑定粒度太粗。
