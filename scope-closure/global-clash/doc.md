# 全局撞名

## 本版本引入的概念

**全局作用域**：传统 `<script src>` 加载的每个文件，顶层 `var` 和函数都登记进同一个全局环境——整个页面共享一张桌子。counter.js 与 timer.js 各自声明 `var count`，以为是各自的私产，其实是同一个变量：后一个声明不新建，只是把它重新赋成 0。

于是事故：点三次「加一」，计数显示 3；下一秒秒表显示的不是 1 而是 4——两边在改同一个数。再点「加一」，计数直接跳到 5。两个互不相识的功能，靠撞名连在了一起。

## 本版本的改动

起始版。index.html 一个计数器（按钮加数字窗）加一个秒表（每秒自走）；counter.js 与 timer.js 各自实现，顶层各声明 `var count`。
