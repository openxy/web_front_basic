# IIFE 私有作用域

## 本版本引入的概念

**IIFE（立即执行函数表达式，Immediately Invoked Function Expression）**：定义即调用的函数，传统写法 `(function(){ ... })()`，箭头写法 `(() => { ... })()`。函数在 JavaScript 里就是一块私有作用域：里面声明的变量，外面看不见。传统 script 没有文件级私有作用域，IIFE 是那个年代的补丁——把整份文件包进一个函数再立刻执行，变量从全局桌面搬进函数内部。

两个文件各包各的：两个 count 互不相识，各自从 0 走各自的路。事故消失，行为与直觉一致。

## 为什么可行、代价是什么

可行的关键是函数作用域加上「函数作为表达式可以立即调用」。代价是每个文件多两层缩进与一对括号——它没有从语言层面解决问题，只是把变量锁进了盒子；文件之间想交换点什么，还是只能走全局。语言级的解法要等到最后一版（模块）。

## 本版本的改动

counter.js 与 timer.js 各自整体包进 IIFE，内部逻辑一字未动（只多一层缩进）。index.html 无改动。
