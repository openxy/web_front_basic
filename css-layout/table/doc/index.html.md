# 解读：index.html（表格拼出的页面骨架）

整个页面就是一张 `<table class="page">`：三行——页头（`colspan="2"` 横跨两列）、主栏 70% + 侧栏 30%、页脚（再横跨）。

- `.page` 直接挂在 table 上：布局即结构、结构即布局，分不开
- `border-collapse:collapse`：去掉单元格默认间隙，否则页头与主体之间会有缝
- `.page td { vertical-align:top }`：td 内容默认垂直居中，多行文字排版要顶部对齐
- 等高列：同一行单元格天然等高，侧栏文字再短也与主栏同高——这是表格的特性，不是我们声明的

页头 `<b>MySite</b>` 加两个 `<span>` 是行内内容顺排：没有对齐工具的年代，「Logo 靠左、登录靠右、垂直置中」无从谈起——这份行内标记从本版起原样保留，第 5 版 flex 只动样式就把它变成真正的导航条。
