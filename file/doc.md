# 文件系统管理内容

## 本版本引入的概念

无（起点）。用一个普通文件夹「我的日记本」存放日记，按日期建子目录，每篇日记一个 txt 文件，可附图片（jpg）和文档（pdf）。

## 局限（推动下一版本的问题）

- 内容无法跨系统、跨设备分享：别人看不到你的文件
- 无法展示：没有排版，只有裸文件
- 无法检索、关联

## 思考

把内容发布给更多人看，最低成本的办法是什么？——写成一堆 HTML 页面放进网站目录。这就是 `static` 版。
