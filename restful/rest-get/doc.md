# GET 列表

## 本版本引入的概念

**REST 的三件事**：URL 指资源（`/posts` 就是帖子这个集合的地址），HTTP 方法表意图（GET = 读，不改动任何东西），JSON 做表示（应答体就是资源的内容）。一行 `fetch(`${API}/posts`)` 不加任何选项，默认就是 GET——读操作是 HTTP 里最朴素的一个词。

应答的 `res.json()` 把 JSON 文本解析成数组，渲染成列表。本案例六版只围绕一套资源 `/posts` 转：读列表、读单个、新建、全量更新、删除、处理状态码——REST 的全部常用动词各上一版。

## 运行环境说明

本案例 runtime 为 shim（接口模拟）：教学站运行页里 fetch 请求被模拟层接住（右下角有「模拟环境」角标），数据落在浏览器 localStorage，刷新保持、运行面板「清数据」重置。示例代码写的是**真实世界形态**——完整地址 `http://localhost:3000`：下载本版本目录后执行 `npx json-server data/posts.json`，同样的代码原样跑在你自己机器上。模拟层只是教学环境里的后端替身。
