# DELETE 删除

## 本版本引入的概念

**DELETE = 让资源消失**。地址仍是个体，方法 DELETE，不需要请求体——删一件事不需要描述它。应答 **204 No Content**：成功，且**没有应答体**，所以代码里不再调 `res.json()`（对空体解析会直接抛错）。

到这里增删改查（CRUD：Create / Read / Update / Delete）凑齐，恰好对应四个 HTTP 动词：POST / GET / PUT / DELETE。REST 的常用半张动词表，六版用完五版。

DELETE 也是幂等的——「删 id 2」发两遍，结果都是「id 2 不存在」，第一次 204、第二次 404（下一版的主角），资源终态一致。

## 本版本的改动

app.js：每个条目在「改」旁边加「删」按钮——DELETE 一发、重拉列表。其余一字未动。

## 试试

1. 删两条再刷新：真没了；POST 新建一条补位，观察 id 又是新的
2. 全删光：空列表 + 空详情；「清数据」可重来
3. 本机 json-server 复现时看 Network：DELETE 应答状态 204、响应体为空
