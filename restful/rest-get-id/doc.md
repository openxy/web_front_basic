# GET 单个资源

## 本版本引入的概念

**路径参数**：`/posts/2` 和 `/posts` 是两个资源——一个是集合，一个是集合里的一件。URL 的层级结构天然表达「集合 / 个体」，id 直接写进地址。点列表条目，GET 单个资源，正文渲染进详情区；读集合像查目录，读单个像调档案。

## 本版本的改动

index.html 列表条目变手型光标、新增 #detail 详情区；app.js 新增 `showPost(id)`——模板字符串拼出 `/posts/${id}`，这是路径参数的全部写法。

## 试试

1. 点不同条目：详情区跟着切换
2. 本机 json-server 复现时，Network 面板对比两次请求的 URL 差别
3. 刷新页面重新点：一切如常——GET 读多少次都不改数据
