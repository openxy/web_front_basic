# 更新：index.html（一张图两条声明，文字环绕出现）

```css
#float-left img{ margin:1em; float:left; }
```

`float:left` 让图片浮动：它**离开文档流但文本绕行**——注意灰边框里发生的三件事：

1. 图片后面的段落占据了图片原来的位置（框从图片身下穿过）
2. 段落里的**文字**却不与图片重叠，顺右侧排开——文字环绕，float 的设计初衷
3. section 的高度不再包含图片：图片「浮」在 section 上方，形成两个层次

对照 absolute：两者都脱离文档流，但 absolute 是文档流彻底当它不存在（文字也压上去），float 是**文本让路不重叠**。另外注意父容器的边框包不住探出的图片——这个「缺陷」在 float-defect 版专门展开。
