# 浮动与清除

## 本版本引入的概念

**浮动（float）**：也会让元素脱离文档流，但机理与目的都不同——它最初为**文字环绕**而生：

- 位置按浮动方向自动计算、不可精确指定（对比定位：设计师指定坐标）
- 不与文本重叠：文本绕着浮动元素流过（对比相对/绝对定位：随便压）
- `clear` 清除浮动：在浮动元素之后的块里清掉一侧的浮动影响，让后面的内容回到正常流

## 本版本的改动

一个页面四段演示（本版信息量大，因为浮动是「另一种脱离文档流」，四段互为对照）：

- 左浮动：图片靠左，文字环绕其右——section 的边框不再包住图片
- 右浮动（未清除）：红框 section 包不住图片，图片探出底部，把下一个 section 的标题顶得提前换行
- 清除浮动：蓝框 section 里加 `<div style="clear:right;"></div>`，边框重新包住图片
- 末段：验证清除之后一切恢复正常

## 关键代码走读

- 图片浮起来后，section 的高度**不再包含**图片——「高度塌陷」是浮动做布局时代最大的坑，clear 是那个时代的解药
- 文本仍保持原定位方式不与图片重叠：段落里的文字绕行，段落的**盒子**其实钻到了图片底下（边框被图片盖住的那部分）——浮动的是盒子，绕行的是行内内容
- 原课程刻意把第三段文字减短，露出图片与文字错位的样子：图片确实浮在文字层之上

## 对照要点

| | 定位（absolute） | 浮动（float） |
| --- | --- | --- |
| 位置 | 设计师指定精确坐标 | 按方向自动挤靠 |
| 与文本 | 可重叠 | 文本绕行 |
| 原空间 | 不保留 | 不保留（盒子上浮） |
| 诞生目的 | 浮层、钉层 | 图文环绕（后来被借去做布局，见前现代布局） |

## 思考题

- 可否直接对 p 元素设浮动清除，而不加空 div？（可以——`#float-clear p{clear:right}`，效果在本例相同；加空元素是原课程的教学写法）
- 高度塌陷的现代解药是什么？（让父元素成 BFC：`overflow:hidden`；或伪元素 ::after 清除——「前现代布局」一章的正题）
