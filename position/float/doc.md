# 浮动

## 本版本引入的概念

**浮动（float）**：也会让元素脱离文档流，但机理与目的都与定位不同——它最初为**文字环绕**而生：

- 位置按浮动方向自动挤靠、不可精确指定（对比定位：设计师指定坐标）
- 不与文本重叠：文本绕着浮动元素流过（对比相对/绝对定位：随便压）

本版只演示最基本的形态：图片 `float:left`，文字环绕其右。

## 本版本的改动

原课程页面第一段：图片左浮动后，section 的边框不再包住图片——浮动元素的尺寸不再计入父元素。

## 关键代码走读

- 图片浮起来后，section 的高度**不再包含**图片——「高度塌陷」的种子在此埋下，本版文字够长看不出来，下一版让它发作
- 文本仍保持原定位方式不与图片重叠：段落里的文字绕行，段落的**盒子**其实钻到了图片底下（边框被图片盖住的那部分）——浮动的是盒子，绕行的是行内内容
- `<img>` 的位置在源码里排在解释段落之后，但浮动后视觉上「提前」了——浮动元素脱离文档流，不再按源码位置占位

## 对照要点

| | 定位（absolute） | 浮动（float） |
| --- | --- | --- |
| 位置 | 设计师指定精确坐标 | 按方向自动挤靠 |
| 与文本 | 可重叠 | 文本绕行 |
| 原空间 | 不保留 | 不保留（盒子上浮） |
| 诞生目的 | 浮层、钉层 | 图文环绕（后来被借去做布局，见前现代布局） |

## 思考题

- 图片浮在 section 边框之上还是之下？（之上——用开发者工具给 section 加个背景色，图片压着它；这正是「浮」的字面义）
