# 静态定位

## 这个项目是什么

「定位」是一个多版本演进的教学项目：同一张李白图片、同一个 460px 版式，每版只改 CSS 里关于 `position` 的几行，走完四种基本定位机制（静态/相对/绝对/固定）再加浮动与 z 轴。相邻版本的 diff 就是一两个 CSS 声明，一眼看穿每种机制改了什么。

原课程每个机制一个独立页面（static.html/relative.html/…），本线按「一版一概念」入册，文件内容原样保留、仅统一改名为 index.html。

## 本版本引入的概念

**静态定位（static）**：`position` 的默认值，不需要写。浏览器按 HTML 代码顺序（即**文档流**）依次排布每个元素。

- block 元素（`p`、`div`、`h2`）独占一行，自上而下摞
- inline 元素（`img`、`span`）依次自左而右，占满一行自动换行

## 关键代码走读

- `#page { width:460px; margin:0 auto; }`：定宽 + 左右 auto，页面内容居中——后面所有版本共用这个版式，不再动它
- 图片与两段文字全部静态：段落把图片「顶」在自己上方，三者各安其位，没有重叠
- 本版没有任何 `position` 声明——它就是后面所有版本的对照组

## 思考题

- 把浏览器窗口拉窄到 460px 以下，`#page` 会怎样？（定宽盒子不会缩，可视区出横向滚动条——文档区域宽于屏幕可视区域时就是这般）
- 下一版让图片「偏移 60px」，猜猜后面的段落会不会跟上来？
