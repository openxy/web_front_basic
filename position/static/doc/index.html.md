# index.html（无任何定位属性的基准页）

样式只有两条规则：`#page` 定宽 460px、`margin: 0 auto` 水平居中；`section p` 一像素灰边框。**这条灰边框是全案例九个版本的观察参照物**——后面每一版的定位机制，都要靠它显形（框跟着走还是留在原地、框包不包得住图片，一眼可辨）。

页面结构：一个 `#page` 装一个 section，里面标题、两段 `<p>`（block，独占一行、自上而下）、一张 `<img>`。没有任何 `position` 声明，一切元素按文档流默认排布——这就是「静态定位」：不是一种设置的定位，而是**没设置**时的定位。

往后每一版只往这个基准页上加几行 CSS、换一个 section id，机制逐版叠加。
