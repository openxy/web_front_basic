# 固定定位

## 本版本引入的概念

**固定定位（fixed）**：绝对定位的变形，参考原点换成**屏幕可视区域（viewport）**而不是文档。页面怎么滚它都不动——顶部固定导航、悬浮客服按钮都是它。

顺带分清两个区域：

- **文档区域**：长宽由内容与样式决定（本版刻意设了 3000px 高）
- **屏幕可视区域**：由浏览器窗口决定，相对不变

文档高于可视区，出滚动条——固定定位的图片钉在可视区右下角，怎么滚都在。

## 本版本的改动

```css
#page{ height:3000px; ... }            /* 拉长文档，逼出滚动条 */
#fixed img{ position: fixed; bottom:30px; right:30px; }
```

`#page` 的 `position:relative` 也删了——fixed 不找祖先当原点，留着没意义。

## 关键代码走读

- `bottom:30px; right:30px`：距可视区右下角各 30px，滚动时纹丝不动
- 对照 absolute 版：那边图片钉在文档坐标上，滚出视区就看不见；这边钉在屏幕上，文档从它背后流过

## 定位小结（四种机制到齐）

| 方式 | 坐标原点 | 偏移方式 | 空间重叠 |
| --- | --- | --- | --- |
| 静态 | 前一元素 | 无 | 不可重叠 |
| 相对 | 原定位位置 | 设计师指定 | 原空间保留，可与兄弟重叠 |
| 绝对 | 最近的已定位祖先 | 设计师指定 | 可与任何元素重叠，顺序由 z-index 定 |
| 固定 | 屏幕可视区域 | 设计师指定 | 同绝对定位，且不随滚动移动 |

选型口诀：**微调用相对（原点留给自己），钉层用绝对（记得给父元素 relative），钉屏用固定**。

## 思考题

- 手机上地址栏收起/展开时，`100vh` 与固定定位的元素会发生什么？（可视区变化，固定元素跟着窗口边走）
- 粘性定位 sticky（导航滚到顶再固定）是第五种机制，一行为固定导航省掉 JS——它像谁？（滚到阈值前像 relative，过后像 fixed）
