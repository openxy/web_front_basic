# 绝对定位

## 本版本引入的概念

**绝对定位（absolute）**：元素就好像被从文档流中删除，失去在正常文档流中所占的位置与空间；并转型为块状盒子，不论原来是何种类型。

新位置以**距离最近的一个非静态定位的祖先元素**为坐标原点；若所有祖先都是静态的，则以 `<body>`（或 `<html>`）为原点。

## 本版本的改动

```css
#page{ position: relative; ... }        /* 新增：给图片当原点 */
#absolute img{ position: absolute; top:60px; right:60px; }
```

- `#page` 设 `position:relative` 正是为了给图片当原点——去掉这行试试，图片会跑去以整个页面为原点
- 图片钉在了红框……不，本例 `#page` 没画边框，钉在的是 `#page` 的右上角（`top:60px; right:60px`），文档流当它不存在

## 关键代码走读

- 段落挤占了原图片所在的空间：与相对定位相反，坑不保留了
- 页面高度被刻意设为 1000px，可以滚动。图片只出现在文档的固定坐标上，滚过去它就「走」了——fixed 版会解决这个问题
- 原课本文本的注释说 3000px，CSS 实际是 1000px，照样能滚出两屏，原样保留

## 常见误区

以为绝对定位总以父元素为原点——是以**最近的非静态定位祖先**为原点，全静态链上溯到 body/html。

## 思考题

- 把 `#page` 的 `position:relative` 删掉，图片钉到哪儿去了？（以 body 为原点，钉到整个页面右上角）
- 绝对定位后的 `img` 变成了块状盒子：`top` 和 `bottom` 同时给值会怎样？（被拉伸——块盒有了高度的可塑性）
