# 相对定位

## 本版本引入的概念

**相对定位（relative）**：先假设元素仍按静态定位确定位置，再以**原位置**为参考原点按偏离值偏移。所占空间仍然保留，可以与其它元素重叠。

- 偏移量用 `top` / `left` / `bottom` / `right` 指定，本版是 `top:60px; left:60px`
- 「原空间保留」：图片挪走了，但后面的段落仍从图片**原位置**下方开始排——空间还替它占着

## 本版本的改动

CSS 加了一条规则：

```css
#relative img{ position: relative; top:60px; left:60px; }
```

图片因此向右下各偏移 60px，压在第二段文字之上（重叠了），而段落位置纹丝不动。

## 关键代码走读

- 偏移的是「显示」，不是「占位」：文档流里图片的那个坑还在，所以段落不会上移补位
- 与浮动的区别：浮动让文本绕行、不与文本重叠；相对定位可以随意压在文本上

## 常见误区

以为相对定位后原位置会被兄弟元素占据——不会，原空间仍保留，只是显示偏移了。

另一个伏笔：设了相对定位但没给偏离值，显示与静态定位无异——但该元素已成为**已定位元素**，可以充当绝对定位的参考原点（absolute 版正是这么用的）。

## 思考题

- 把 `top:60px` 改成 `top:-60px`，图片去哪了？（向上偏移，压住标题——偏离值可为负）
- 只写 `position:relative` 不写偏移，页面有变化吗？图片的身份变了吗？
