# 浮动的清除

## 本版本引入的概念

**clear（清除浮动）**：对某个块元素声明 `clear: left / right / both`，是命令它把自己放到**此前相关浮动元素的下方**——浮动元素探出多深，清除元素就下移多深，父元素的底边随之被重新撑起。

## 本版本的改动

- 第三段升级为清除演示段（蓝框）：在浮动图片之后补一个内容为空的元素 `<div style="clear:right;"></div>`，蓝框边框重新包住图片
- 新增第四段：验证清除之后，后面的内容恢复正常

## 关键代码走读

- 空元素零内容零高度，唯一职责是「垫」在浮动元素下方，把父元素的底边顶下去——它自己也是文档流内的普通块，撑起的高度就是父元素新收复的失地
- 请比较红框（未清除）和蓝框（已清除）对图片的包含关系：一行 `clear:right`，高度塌陷与顶歪后续一并解决
- 原课程刻意减短第三段的诗人简介，让图片下探露出错位——清除之后，错位一并消失
- 第三段的 h2 仍然提前换行：clear 垫起的是本段的**底边**，治不了顶上被上一节探出图片挤过的**开头**——所以第四段才真正回到正常

## 思考题

- 可否直接对 p 元素设浮动清除，而不加空 div？（可以——`#float-clear p{clear:right}`，效果在本例相同；加空元素是原课程的教学写法）
- 空元素为样式目的污染了 HTML 结构——有没有不动 HTML 一根毫毛的办法？（有——下一版用 CSS 伪元素凭空「造」出这个空元素）
