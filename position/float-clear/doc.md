# 浮动的清除

## 本版本引入的概念

**clear（清除浮动）**：对某个块元素声明 `clear: left / right / both`，是命令它把自己放到**此前相关浮动元素的下方**——浮动元素探出多深，清除元素就下移多深，父元素的底边随之被重新撑起。

## 本版本的改动

上一版的事故现场原样保留，只加一行：在浮动图片（及其简介）之后补一个内容为空的元素 `<div style="clear:right;"></div>`——

- 红框的下边缘从图片腰上穿下来，把图片完整包住：高度塌陷收回
- 下方那段不再绕行，h2 回到左边缘：顶歪的版面复位（它的标题也换成了「验证我又正常了」）

## 关键代码走读

- 空元素零内容零高度，唯一职责是「垫」在浮动元素下方，把父元素的底边顶下去——它自己也是文档流内的普通块，撑起的高度就是父元素新收复的失地
- 与上一版对照着看红框的下边缘：一行 `clear:right`，高度塌陷与顶歪后续一并解决
- clear 挂在**空元素**上而不是 section 自己身上：clear 约束的是元素自己的上边缘位置，section 若自己 clear，会把整个段推到别人家浮动图片的下方去（本例上方没有别的浮动，看不出差别，但语义不同）

## 试试

- 删掉那行空元素：红框立刻塌回去、下方再次被顶歪——两版之间一键往返
- 把空元素挪到简介段落之前：图片上方多出一块空白，说明 clear 不认位置只认「此前」的浮动元素
- 把 `clear:right` 改成 `clear:left`：本例的图片是右浮动，左边没有浮动元素可让——空元素留在原地，红框照样塌着

## 思考题

- 可否不加空元素，直接对简介的 p 设 `#float-right p{clear:right}`？（可以——效果在本例相同；加空元素是原课程的教学写法，语义上「垫底」的意图更直白）
- 空元素为样式目的污染了 HTML 结构——有没有不动 HTML 一根毫毛的办法？（有——下一版用 CSS 伪元素凭空「造」出这个空元素）
