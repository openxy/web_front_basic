# 更新：index.html（缺陷版原样保留，只多一行 HTML）

CSS 与上一版完全相同。全部修复就一行——浮动图片之后、section 结束之前：

```html
<div style="clear:right;"></div>
```

`clear:right` 的意思是：**我这个元素的顶边要低于它前面的右浮动元素**。空 div 本身不占视觉空间，但它把「低于图片底边」这个约束带进了 section 的正常流——section 的高度重新包含图片，红框完整包住，第二节复位。

一句话理解 clear：不是「清除浮动元素的浮动」，而是「让正常流里的下一个元素躲开浮动元素」。代价是每个要闭合的容器都得塞一个空元素、纯为布局服务——HTML 被迫携带表现语义，清除的零侵入写法见 clearfix 版。
