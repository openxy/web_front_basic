# CSS 定位（position 案例）

## 本案例教什么

先讲四种基本定位机制（静态/相对/绝对/固定）与 z 轴叠放，再走浮动四部曲：浮动、浮动的缺陷、浮动的清除、伪元素清除。浮动是「为文字环绕而生」的历史机制，它的缺陷与清除是理解现代布局为什么抛弃浮动的关键。

原课程页面原样入册（浮动一章拆为浮动/缺陷/清除三版，单一例子贯穿）；z-index 与 clearfix 两版依原课程文档新写。

## 版本导览

| # | 版本 | 概念要点 |
| --- | --- | --- |
| 01 | [静态定位](#v=position/static) | 文档流默认排布，一切定位机制的基准形态 |
| 02 | [相对定位](#v=position/relative) | 以原位置为原点偏移，原空间保留 |
| 03 | [绝对定位](#v=position/absolute) | 脱离文档流，以最近非静态祖先为原点 |
| 04 | [浮层与 z 轴](#v=position/z-index) | 定位层叠放次序：图片角标的最小实现 |
| 05 | [固定定位](#v=position/fixed) | 原点换成屏幕可视区域；附四种机制小结表 |
| 06 | [浮动](#v=position/float) | 为文字环绕而生：文本绕行不重叠，父高度已不含它 |
| 07 | [浮动的缺陷](#v=position/float-defect) | 一行代码都没写错的事故现场：父高度塌陷 |
| 08 | [浮动的清除](#v=position/float-clear) | 空元素挂 clear 垫回父高度 |
| 09 | [伪元素清除浮动](#v=position/clearfix) | .clearfix 用 ::after 代劳空元素，HTML 零侵入 |

## 重点与边界

- 重点：每种机制的坐标原点、是否脱离文档流、重叠规则；浮动一章改一行代码看一次事故与修复
- 边界：表格→浮动→flex→grid 的布局演化全景见 css-layout 案例；响应式设计不在本案例
