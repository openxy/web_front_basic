# 更新：index.html（同一张图改成右浮动，多一个受害段落）

CSS 只改一个词：`float:right`。页面多一个观察位：第二个 section「我被迫换行了...」。

事故现场：第一节简介文字不够长，灰框（section）底部从图片腰上穿过——**父元素高度不含浮动图片**（上一版已见）。图片下半截探出红框，压进第二节的地盘；第二节的文本不与浮动图片重叠（环绕机制），只得绕行提前换行。

注意：**一行代码都没有写错**。float:left 时同样探出，只是左下角恰好没有内容受害。浮动天生让父容器高度塌陷——「文字环绕」与「父高度塌陷」是同一机制的两面：特性还是缺陷，只看场景。修复见 float-clear 版。
