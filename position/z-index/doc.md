# 浮层与 z 轴

## 本版本引入的概念

**定位层与 z-index**：多个绝对定位的元素在原文档空间之上形成多个定位层，获得 Z 轴视角；`z-index` 属性决定这些层的叠放顺序——数字大者在上，可为负。

绝对坐标不受普通元素限制，所以常用于浮层窗口、角标徽章之类「钉在某处」的效果。本版做的是后者：给右下角……不，右上角的图片钉一枚红色圆形角标。

> 本版为依《Web 前端开发技术·06 定位》「用途：浮层与 z 轴」一节新写的组合示例（原课程目录无对应文件），以 absolute 版为基底。

## 本版本的改动

- 图片外面包了一层 `<div id="photo">`：绝对定位从 `img` 挪到 `#photo` 上，`img` 改设 `position:relative; z-index:1`——让它也成为已定位元素，取得 z 轴参赛资格
- 新增 `<span class="badge">`：绝对定位，原点是最近的已定位祖先 `#photo`，`top/right:-8px` 探出图片角，`z-index:2` 压在图片上

## 关键代码走读

- `z-index` 只对**已定位元素**生效：img 若保持静态，徽章与它不在同一场竞赛里（定位元素天然画在静态内容之上，根本轮不到 z-index 出场）
- 两个都定位了、都没给 z-index 时，DOM 顺序决定谁在上（后者胜）
- `border-radius:11px` 把方块圆成圆点，宽高 22px 的一半——纯装饰，与定位无关

## 试试

- 把 `.badge` 的 `z-index` 改成 `-1`：徽章钻到图片背后，只剩探出的一圈红色
- 把 `#photo img` 的 `z-index` 改成 `3`：图片整个盖住徽章
- z-index 相同呢？回到 DOM 顺序：徽章在后，徽章在上
