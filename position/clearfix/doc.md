# 伪元素清除浮动（clearfix）

## 本版本引入的概念

- **伪元素（::after）**：普通选择器只能选中标记元素，伪元素选择器能选中「内容级」目标——第一个字符、第一行，以及挂在元素**末尾**的一个「伪」子元素（现代写法用双冒号，与伪类的单冒号区分）
- **内容生成（content）**：允许浏览器解析文档时在样式层动态生成内容——凡「内容跟着结构走而非作者手写」的场合
- **.clearfix**：三者的合体应用——把上一版手写的空 div 换成样式层自动生成的「假 div」

> 本版为依《Web 前端开发技术·05 伪类、伪元素与内容生成》「内容生成」一节新写的组合示例，以 float-clear 版为基底（books.openxy.com/web_front/05/）。

## 本版本的改动

上一版原样沿用，只是清除的执行者换了人：

- 删掉 `<div style="clear:right;"></div>`，给红框 section 挂 `class="clearfix"`——HTML 结构零改动
- CSS 新增 clearfix 规则组：由 `.clearfix::after` 在 section 末尾生成空内容并清除浮动

## 关键代码走读

```css
.clearfix::before,
.clearfix::after {
  content: " ";
  display: table;
}
.clearfix::after { clear: both; }
```

逐句拆开：在 .clearfix 元素的前后各插入一段空内容（`content: " "`），并把它的盒子类型设为 `table`——借表格盒子的布局特性把浮动高度重新计入父元素；`::after` 再挂 `clear: both`，代行上一版空 div 的职责。用法上只需给父元素挂一个 clearfix 类，比空标记方案干净且可复用。

- `::before` 的 `display:table` 在防**边距塌陷**：margin 折叠会把父元素与首个子元素的 margin 合并，表格盒隔开它
- 上一版空 div 干的活一件不少，只是「雇员」从 HTML 里的标记元素换成了 CSS 生成的伪元素

## 与上一版对照

| | 空元素法（上一版） | clearfix 法（本版） |
| --- | --- | --- |
| HTML | 每处补一个空 div | 挂一个类即可 |
| 复用 | 复制粘贴标记 | 一份 CSS 全站通用 |
| 语义 | 空标记污染结构，爬虫与读屏软件陪它绕路 | 结构零侵入 |

## 试试

- 给下方验证段也挂上 clearfix 类：毫无变化——对没有浮动子的元素，clearfix 是无害的
- 删掉 `::before` 整段规则：本例视觉不变（没有边距可塌），但在有 margin 的真实页面上差别会露出来

## 思考题

- 高度塌陷还有别的现代解药吗？（让父元素自己成为 BFC：`overflow: hidden`；或干脆不用浮动——见「前现代布局」与弹性盒子布局）
- 为什么说 clearfix 是「伪类、伪元素与内容生成」三者的合体案例？（生成的盒子靠伪元素选中、内容由 content 生成、挂到类上随处复用——一条样式链走完三讲）
