# 布局与区块

## 本版本引入的概念

版式升级为两栏：正文主栏 + **分类导航侧栏**。这一版同时回答「页面怎么摆」和「页面由什么组成」两个问题。

**区块（block）的划分**是本版的设计动作：反复出现的信息块应当作为独立单元划出来——

+ 站点头、站点底、主导航：全站区块，每个页面都有
+ 分类导航（诗 6 / 词 1 / 文 1，点击带 `?category=` 参数跳列表页）：内容区块，只出现在与诗文相关的页面上
+ 相关文章、访问统计：区块思想一样，本案例不展开

**布局的实现**走 grid：`.site-body` 声明 `display: grid; grid-template-columns: 1fr 13rem`，主栏与侧栏两列排开。三拍：

+ **是什么**：grid 把容器划出行列，子元素按列宽入位——布局从「浮动硬掰」变成「格子就座」
+ **怎么兑现**：浏览器渲染时先算格子尺寸再摆放子元素；`align-items: start` 让侧栏不被拉伸。格式化上下文接管了这一层的排布规则
+ **为什么**：对比 css-layout 案例的八代演化（表格布局→浮动→栅格→grid），grid 是「描述期望版式」而非「操纵元素位置」——又一个声明式表层

HTML 这边每页把 `<main>` 包进 `.site-body` 两栏容器、补上 `<aside class="sidebar">`；CSS 在 v4 基础上追加一节布局段。侧栏是手写的，三个分类的篇数数错就得手改——这个重复交给 v7 的 JS 渲染去消灭。
