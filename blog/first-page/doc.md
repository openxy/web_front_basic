# 首页骨架

## 本版本引入的概念

从零开始一个站点。第一版只有一页 `index.html`，但它回答了建站的前两个设计问题：

+ **内容类型**（中心内容先行）：个人博客最想传递给读者的是什么？——博文。8 篇刘禹锡诗文就是本站的内容类型 Post，每篇由标题、年代、分类、标签、摘要、正文（诗文＋题解＋注释）、出处、是否置顶这些字段组成。先把中心内容的字段分清楚，后面的页面、接口、存储都围绕它长出来
+ **文档结构**（HTML 语义）：`header` 站点头、`nav` 导航、`main` 主内容、`article` 每篇诗文、`footer` 站点底——整页按「区块」组织，不靠 `div` 堆砌。`time`、`mark` 这些语义标签也各就各位

`article` 上的 `pinned` class、导航里的菜单项，此时都没有视觉效果——它们是给后续版本预留的钩子：v4 上样式后置顶高亮才会亮起来，v2 多页成型后导航才可点。

## 与下一版的界线

标题此刻只是文字，点不动；整个站只有一页。多页互跳与 URL 布局是下一版的事。

## 观察

- 用浏览器打开本页：能读，但哪里也去不了
- 数一数 `<article>` 的数量：8 篇诗文，置顶两篇排最前（数据视角的排序，与样式无关）

## 思考

+ 如果内容不是「诗文」而是商品、课程，页面上会先变的是哪一块？
+ 一篇文章的字段里，哪些是给「人」看的，哪些是给「检索」用的（分类、标签、年代）？
