# 传统表单

> 本案例共 6 版，总览见案例 README（在线站案例菜单 → form-ajax 总览）。本版是出发点：先看清原生表单够用在哪、不足在哪。

## 本版本引入的概念

**传统表单提交**：浏览器内置的行为，不需要任何 JS——

- 收集表单里所有**带 name** 的控件的值
- 按 method 组装请求（`POST /register`），**整页跳转**到 action 指向的地址
- 服务器处理后返回一个**全新的页面**，浏览器整页替换渲染

点一下「注册」试试。本站是纯静态托管，没有后端，你会直接看到 404——这本身就是传统表单的写照：它必须有后端配合才有意义。

## 它够用，但不足在哪

- **整页跳转**：页面状态全部丢失——已填的其它表单、滚动位置、未保存的编辑，一并归零
- **必须有后端返回整页**：服务器要为每一次提交渲染完整 HTML，哪怕只想回一句「注册成功」
- **反馈粗糙**：填错了要提交、等结果、看返回的错误页，往返一趟才能改；校验只能靠 HTML 属性（`maxlength`、`required`），提示的样子不受你控制
- **每一次交互都是一次航行**：改一个字段也要重新走完整流程——后面几版要解决的正是这些

## 关键代码走读

- `action="/register" method="post"`：提交的目标与方式——传统表单的全部行为学都在这一个标签的两个属性里
- 控件必须带 `name`：它是请求参数的名字（`pwd1=...`）；`id` 服务 JS 与无障碍链接，不进请求
- `<button type="submit">`：触发表单提交的默认按钮——表单里的按钮默认就是它
