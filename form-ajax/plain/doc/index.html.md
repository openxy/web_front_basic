# index.html（没有一行 JS 的原生表单——整条案例线的对照基线）

值得看的正是「什么都没做」时浏览器的默认行为：

- 每个 `<input>` 带 `name`——**name 是浏览器收集数据的键**，没有 name 的控件提交时直接不被收集
- `<form action="/register" method="post">`——提交目标与方法
- `<button type="submit">`——点它触发 form 的提交：浏览器把三个输入框的值收进请求体，**整页跳转**到 action 指向的地址，等服务器返回一个新页面

在本站运行这个版本：点「注册」后页面走掉（本地没有 /register 服务，落在错误页）——这不是 bug，是原生表单的真实形态。案例全线的演进动机就在这：**跳转打断一切、网络往返全部要等**。后面五版一步步把行为接管回页面内，对照时以这版为「原点」。
